# מערכת שיבוץ מעונות

מערכת זו נועדה ליצור אוטומטית דוח שיבוץ שעות עבור אחראיות הגיל הרך, מדריכות מעונות וכדומה. התוכנה מקבלת נתוני שכר של העובדות ורשימת מעונות, ומפיקה דוח אקסל מרוכז הכולל את חלוקת שעות העבודה והתקציב לכל חודש.

## איך להוריד ולהפעיל את התוכנה?

כדי להתחיל להשתמש בתוכנה, בצעי את השלבים הבאים:

1. בצידו של עמוד זה, חפשי את הכותרת **Releases** (גרסאות).
2. לחצי על הגרסה העדכנית ביותר, שמופיעה עם התווית **Latest** (האחרונה).
3. בעמוד שייפתח, תחת הכותרת **Assets**, לחצי על הקובץ שמסתיים באותיות `.exe` כדי להוריד אותו למחשב שלך.
4. לאחר שההורדה הסתיימה, לחצי עליו פעמיים כדי להפעיל את התוכנה (בפעם הראשונה עשויות לעבור מספר שניות עד שהיא תיפתח, אנא המתיני בסבלנות).

**שימי לב:** ייתכן וקופצת הודעת אזהרה כחולה של Windows בעת ההפעלה (מכיוון שזו תוכנה חדשה). אם זה קורה:
* לחצי על **"מידע נוסף"** (או "More info").
* לאחר מכן, יופיע כפתור חדש למטה - לחצי על **"הפעל בכל זאת"** (או "Run anyway").

## קבצי קלט נדרשים להפעלת התוכנה

כדי שהתוכנה תעבוד, תזדקקי לשני קבצים:

1. **קובץ מעונות (Excel):**
   - קובץ אקסל רגיל (בסיומת `.xlsx` או `.xls`).
   - **עמודה ראשונה (חובה):** שם המעון.
   - **עמודה שנייה (רשות):** סמל המעון.

2. **קובץ משכורות (Exel / CSV):**
   - קובץ שנשמר מתוך אקסל בפורמט `.Exel`, או `.csv` (נתמך קידוד עברית חלונות או UTF-8).
   - חובה לוודא שהקובץ כולל בדיוק את כותרות העמודות הבאות: `'שם פרטי'`, `'שם משפחה'`, `'תקופה'`, `'סהכ כללי עלות מעביד'`.
   - עמודת ה'תקופה' חייבת להיות מוקלדת בפורמט של שנה/חודש (לדוגמה: `2024/05`).

## אופן השימוש

1. **פתחי** את התוכנה ("מערכת שיבוץ מעונות") במחשב.
2. **בחרי** את קובץ המעונות ואת קובץ המשכורות שהכנת, באמצעות הכפתורים המתאימים במסך.
3. **הזיני** את התעריף השעתי (בש"ח) ואת כמות השעות הנדרשת למעון בחודש. (אם לא תשני, התוכנה תשתמש בברירת המחדל: 220 ש"ח ושעה אחת למעון).
4. **לחצי** על הכפתור **"הפקת דוח שיבוץ"**.
5. בחלון שיקפוץ, **בחרי** היכן את רוצה לשמור את קובץ התוצאה הסופי במחשב שלך (הקובץ יישמר כאקסל).

## אלגוריתם השיבוץ ומועדי עבודה

התוכנה מבצעת חלוקה חכמה של שעות העבודה בהתאם לתקציב הזמין לכל עובדת (מחושב על בסיס "עלות המעביד" ו"התעריף השעתי"). בנוסף, התוכנה משבצת אוטומטית את תאריכי העבודה כך שיפוזרו באופן שווה ונוח על פני החודש.

מערכת השיבוץ מזהה ומסננת באופן אוטומטי ימים שאינם ימי עבודה, ולא תשבץ בהם שעות:
- ימי שישי ושבת.
- חגי ישראל (כגון ראש השנה, יום כיפור, סוכות וכו').
- ערבי חג.
- מועדים לאומיים (יום הזיכרון, יום העצמאות, יום ירושלים).
- **הערה:** יום השואה מוגדר בתוכנה כיום עבודה חוקי לשיבוץ.
