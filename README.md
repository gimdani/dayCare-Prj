# מערכת שיבוץ מעונות

מערכת זו נועדה ליצור אוטומטית דוח שיבוץ שעות עבור אחראיות הגיל הרך. התוכנה מקבלת נתוני שכר של העובדות ורשימת מעונות, ומפיקה דוח אקסל מרוכז הכולל את חלוקת שעות העבודה והתקציב לכל חודש.

## קבצי קלט נדרשים

1. **קובץ מעונות (Excel):**
   - קובץ בסיומת `.xlsx` או `.xls`.
   - עמודה ראשונה חובה: שם המעון.
   - עמודה שנייה (אופציונלי): סמל המעון.

2. **קובץ משכורות (CSV):**
   - קובץ בפורמט `.csv` (נתמך קידוד UTF-8 או Windows-1255).
   - חובה לכלול את העמודות הבאות בדיוק: 'שם פרטי', 'שם משפחה', 'תקופה', 'סהכ כללי עלות מעביד'.
   - עמודת ה'תקופה' חייבת להיות בפורמט `YYYY/MM` (לדוגמה: 2024/05).

## אופן השימוש

1. פתח את התוכנה ("מערכת שיבוץ מעונות").
2. בחר את **קובץ המעונות** ואת **קובץ המשכורות** באמצעות הכפתורים המתאימים.
3. הזן את ה**תעריף השעתי** (בש"ח) ואת **כמות השעות למעון בחודש** (ברירת המחדל היא 220 ש"ח ושעה אחת למעון).
4. לחץ על כפתור **"הפקת דוח שיבוץ"**.
5. בחר היכן לשמור את הקובץ הסופי (`.xlsx`).

## אלגוריתם השיבוץ ומועדי עבודה

התוכנה מבצעת חלוקה חכמה של שעות בהתאם לתקציב הזמין לכל עובדת (על בסיס עלות המעביד והתעריף השעתי).
בנוסף, התוכנה משבצת אוטומטית את תאריכי העבודה כך שיפוזרו באופן שווה על פני החודש.
מערכת השיבוץ מסננת באופן אוטומטי ימים שאינם ימי עבודה:
- ימי שישי ושבת.
- חגי ישראל (כגון ראש השנה, יום כיפור, סוכות).
- ערבי חג.
- מועדים לאומיים חילוניים (יום הזיכרון, יום העצמאות, יום ירושלים).
- **הערה:** יום השואה מוגדר כיום עבודה חוקי לשיבוץ.
